# Video transcripts (YouTube, Instagram, TikTok, Facebook)

Returns the spoken text of public videos as JSON, one item per URL.

Author: Pom Labs. Disclosure: both routed Actors are built by the author and are paid per result.

## Example prompts

Prompts this skill handles:

- "Summarize this for me: https://www.youtube.com/watch?v=jNQXAC9IVRw"
- "I need an SRT file of this Reel, translated to English"
- "Get the transcripts of these 12 TikToks so I can search them"

Out of scope (the boundary):

- "Transcribe this mp3 from my laptop" — this skill reads public video links only; use a local speech-to-text tool instead.

## Prerequisites

- Apify account ([sign up](https://apify.com))
- Authentication via one of:
  - `apify login` (OAuth, if using the Apify CLI)
  - `APIFY_TOKEN` environment variable
  - Token from [Apify Console → Settings → Integrations](https://console.apify.com/settings/integrations)

## Workflow

1. Pick the Actor by the link's domain (table below). Split mixed lists into one call per Actor.
2. Build the input from the fields below. Leave `includeTimestamps` `false` for summaries to save tokens; set `maxDurationSeconds` on social videos so cost is bounded.
3. Estimate the cost. Above 50 videos, tell the user the estimate and wait for a yes.
4. Run the Actor, read the dataset, check `status` on every item before using `transcript`, and report failed URLs one by one.

## Actor routing

| User need | Actor ID | Tier | Best for |
|-----------|----------|------|----------|
| YouTube videos, Shorts, live and embed links, or the 11-character id | `pomlabs/youtube-transcript-scraper` | community | Caption tracks (manual captions win over auto-generated); $0.003 per transcript |
| Instagram Reels and video posts, TikTok videos, Facebook videos and Reels | `pomlabs/social-video-transcript` | community | Platform captions when present, otherwise speech-to-text; $0.01 per transcript, + $0.008 per extra minute of speech-to-text |

Translation costs + $0.002 per language on both. Prices are the ones on each Actor's Store page; check there if they matter to the user.

## Input fields

| Field | Actor | Meaning |
|-------|-------|---------|
| `urls` (required) | both | Array of video links |
| `languages` | YouTube | Caption languages in order of preference, e.g. `["pt","en"]` |
| `language` | social | `auto` (default) or a code such as `en`, `pt`, `es` to force the speech-to-text language |
| `translateTo` | both | Extra languages to return with the same timestamps, e.g. `["en"]` |
| `includeTimestamps` | both | `true` adds a `segments` array with start time and text |
| `subtitleFormat` | both | `srt` or `vtt` adds a ready subtitle file as text; default `none` |
| `maxDurationSeconds` | social | Longer videos are skipped and not charged |

Output worth keeping: `status` (`ok` or an error code), `title`, `transcript`, and `segments` when requested. YouTube adds `channelName`, `language`, `isAutoGenerated` and `availableLanguages`; the social Actor adds `platform`, `author`, `durationSeconds` and `source`.

## Calling Actors

### Option A: Apify CLI

    apify actors call "pomlabs/youtube-transcript-scraper" \
      -i '{"urls":["https://www.youtube.com/watch?v=jNQXAC9IVRw"],"languages":["en"],"includeTimestamps":false}' \
      --json \
      --user-agent apify-awesome-skills/apify-video-transcripts \
      2>/dev/null

    apify actors call "pomlabs/social-video-transcript" \
      -i '{"urls":["https://www.tiktok.com/@scout2015/video/6718335390845095173"],"language":"auto","includeTimestamps":false,"maxDurationSeconds":600}' \
      --json \
      --user-agent apify-awesome-skills/apify-video-transcripts \
      2>/dev/null

The JSON output has `run.status` (`SUCCEEDED` when done) and the dataset id at `storage.defaultDatasetId`. Read the items:

    apify datasets get-items DATASET_ID --format json \
      --user-agent apify-awesome-skills/apify-video-transcripts 2>/dev/null

### Option B: Apify MCP connector

With the hosted MCP server at <https://mcp.apify.com>, call `call-actor` with the Actor ID and the same input. If it answers with status `RUNNING`, call `get-actor-run` with the `runId` until it is `SUCCEEDED`, then `get-dataset-items` with the dataset id.

## Troubleshooting

- Item with `status` other than `ok` → that video has no captions, is private or was removed. Report it for that URL and continue with the others; failed or skipped videos are not charged.
- Empty `transcript` on a music or silent video → nothing was spoken. Say so; do not invent text.
- The run is still going after several minutes → the batch is large. Keep each call to 25 URLs or fewer.
- Out of credit or usage-limit message → tell the user; do not retry.
