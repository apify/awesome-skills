# Observed gotchas (live runs, 2026-10-23, free plan)

Each item was seen in a real run, and the run id is given. Only behavior the Actors' READMEs do not already state is listed; documented behavior, such as LinkedIn's result cache and its usually empty apply URLs, is applied in the decision rules instead.

- **Unbounded default paging.** Google Jobs pages without limit by default. In the 30 days to 2026-10-07, 21% of its public runs timed out. With one page and 10 results, each run took about 35 seconds and billed exactly one page event; 3 of 3 runs succeeded. Runs fp5xX3zKUKh3KRIb6, JaVAYPeUEWjoWJQoF, nksAivU4xC4Z9etsJ.
- **One job, two ids.** The same nursing requisition came back twice in one Google Jobs page, via Indeed and via Glassdoor, under different `htidocid` values. The raw `job_id` was never identical across two queries for the same listing. Runs fp5xX3zKUKh3KRIb6, JaVAYPeUEWjoWJQoF.
- **A city is not a radius.** A "Denver, CO" search returned postings in Gunnison, Sterling and Cañon City, 100 to 200 miles away. Run fp5xX3zKUKh3KRIb6.
- **Apply links rarely reach the employer.** Only 1 of 30 Google Jobs rows had an apply link on a routed ATS. The rest pointed at aggregators, LinkedIn, or custom career sites. Runs above.
- **The employer's board still confirms.** A row reachable only through aggregators matched AdventHealth's Workday requisition R-0407372 ("CVICU Assistant Nurse Manager", posted 4 days earlier). That came from a 40-job filtered pull costing $0.005; the whole site holds 2,000 jobs. Run 46kzbhmuGLLWh3baE.
- **Workday location text is a facility name** ("ADVENTHEALTH LITTLETON"), not a city and state. Run 46kzbhmuGLLWh3baE.
- **LinkedIn seeds confirm well on Ashby.** Of 37 similar and also-viewed jobs, 12 employers resolved on Ashby by name, and all 12 titles were live. Run jLaiVbRLHTAfrL1wJ.
- **Unfiltered sweeps bill the wrong rows.** With no location filter, 18 of 40 billed Ashby rows were outside the US, and two employers took 22 of the 40. Greenhouse showed the same pattern over 200 boards in 253 seconds. Runs 9nqFAM1Ih22UpkQr8, ojI0d9xKH1WGLw5tt.
- **A zero needs a control.** A JazzHR search for Colorado nurse managers returned 0 rows. A control search for "nurse" returned rows, so that zero was real. Runs AWBvGNbudLVSsjfzq, 24aIYCcMDBFiApEuI.
- **The free plan allows 5 concurrent runs.** A sixth launch was refused with HTTP 402 "concurrent-runs-limit-exceeded".
- **Guessed board names fail.** In a test session the agent invented Greenhouse tokens and Ashby slugs from company names ("snorkelai", "runwayml", "hebbia-ai"). 11 of 15 Greenhouse lookups and 4 of 9 Ashby slug lookups came back "board does not exist on the public API". Ashby's name matching resolved real names; Greenhouse needs a token from a real link. Runs 1ylR5glKEynpwZRE7, FuyYoVF37BHZ7gbGm.
- **A name lookup can land on another employer.** "UCHealth" (Colorado) resolved on Oracle to UC Health Careers in Cincinnati: all 10 billed rows were Cincinnati roles, none a nurse manager. `searchText` is the board's full-text search, not a title filter, and at the time the board ignored the "Colorado" filter. Since the Actor's 2026-10-29 update, a location with no matching jobs returns no rows and a warning naming where the board's jobs are. The same run found no Oracle board for HCA Healthcare, AdventHealth, Intermountain Health or Christian Living Communities. Run liltaZsHDe5oSYjSw.
- **LinkedIn search is the cheapest breadth.** A past-month "nurse manager" search near Denver returned 150 listings, none from cache, for $0.0015. Five Google Jobs pages for the same search cost $0.45 and returned 38 rows, 30 of them tagged only "Colorado". Runs Cc4xWhVXuP5judzLS, iuGT7pigs2mqwiwrU.
