# YouTube channel and playlist transcripts for RAG

Turn a YouTube channel, playlist or list of videos into one dataset of caption transcripts, one row per video, in a shape that is ready to chunk and embed.

Disclosure: the author of this skill built the Actor it routes to (`prospect_antechamber/youtube-transcript-bulk`). The Actor is paid on the Apify Store: $2 per 1,000 successful transcripts ($0.002 each), plus Apify platform usage (compute and proxy). No referral or tracking parameters are used.

## Example prompts

Prompts this skill handles:

- "Get the transcripts of the last 100 videos on https://www.youtube.com/@veritasium so I can load them into my vector DB"
- "Download English subtitles as SRT for every video in this playlist: https://www.youtube.com/playlist?list=PL..."

Out of scope (the boundary):

- "Transcribe this video that has no captions" (this Actor reads existing captions only, with no speech-to-text). Use a speech-to-text Actor or tool instead.

## Workflow

1. Collect the YouTube URLs: video, Shorts, `youtu.be`, bare video IDs, playlist URLs, or channel URLs (`/@handle`, `/channel/…`, `/c/…`). They can be mixed in one list; duplicates are removed.
2. Build the input:
   - `urls` (required): the list above.
   - `maxVideosPerSource` (default 50): cap per playlist, or per channel tab.
   - `languages` (default `["en"]`): caption language codes in priority order. If none match, the first available track is returned and the `language` field says which.
   - `preferManual` (default true): prefer human-uploaded captions over auto-generated.
   - `outputFormats` (default `["txt"]`): add any of `txt`, `srt`, `vtt`. JSON segments are always included.
   - `includeChannelShorts` (default false): channel URLs read only the Videos tab. Turn this on, or pass a `…/shorts` URL, to include Shorts; pass `…/streams` for live streams.
   - Leave `proxyConfiguration` at its default (Apify RESIDENTIAL). YouTube blocks datacenter proxies heavily.
3. Run the Actor. Cost is $2 per 1,000 successful transcripts plus platform usage (the author's tests measured platform usage at about $2.80–3.70 per 1,000 transcripts); confirm with the user before large channel runs.
4. Deliver the results: the number of videos, how many have an `error`, and the dataset link. Each item has `videoId`, `url`, `title`, `channel`, `channelUrl`, `durationSec`, `language`, `isAutoGenerated`, `segments`, `segmentCount`, `text`, `srt`, `vtt` and `error`.

Example input:

```json
{
  "urls": ["https://www.youtube.com/@veritasium", "https://www.youtube.com/playlist?list=PL..."],
  "maxVideosPerSource": 50,
  "languages": ["en"],
  "outputFormats": ["txt", "srt"]
}
```

## Troubleshooting

- A row has `error` such as `TranscriptsDisabled`, and no text: the video has no captions. Every video still gets a row, so nothing is dropped silently.
- A channel returned fewer videos than expected: raise `maxVideosPerSource`, and add `includeChannelShorts` or a `…/streams` URL if needed.
- Many videos are blocked: you probably switched to a datacenter proxy. Go back to the default RESIDENTIAL, or turn on `residentialFallback`.
- The wrong language came back: no requested language was available, so the first track was returned. Check the `language` field.
